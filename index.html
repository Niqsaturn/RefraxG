Explore the science behind Refrax G

Refrax G combines geographic reference data with radio propagation and ionospheric models. Use the map to explore published environmental context and evaluate conditional electromagnetic scenarios. A calculated field is not evidence that a receiver measured a signal at a particular location.

How to use the observatory

Select a layer and compare its data source, coverage and units before interpreting a pattern. Zoom to examine available geographic geometry, then isolate a field to avoid conflating independent visual layers. Where the source has no coverage, treat the value as unknown rather than zero.

Understand the limits

Propagation depends on frequency, source geometry, materials and boundary conditions. Model assumptions must be recorded if results are to be reproduced. For more detail, read the observatory guide, propagation physics and data and API documentation.
