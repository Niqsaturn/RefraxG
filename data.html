Data, provenance and the public API

Refrax G combines public reference datasets and physically defined calculations. The availability of each source changes over time. An inventory of facilities or receivers is not a measurement of activity, and a modeled ionosphere is not a local RF sensor. These distinctions are central to the public API.

Read a snapshot

The public gateway provides a bounded global data contract. A successful health response means the service is reachable, not that every source feed is current.

curl https://en-route.ringtail-anoles.ts.net/refrax-api/v1/health
curl https://en-route.ringtail-anoles.ts.net/refrax-api/v1/snapshot

Inspect the status, source timestamp and stale indicators before using the data. Reuse a snapshot when investigating a single scenario instead of repeatedly requesting the same product.

Source categories

SourceInterpretation
International HF schedulesPublished reference sites and schedule membership, not measured emissions.
Public receiver directoryCoarse geographic listing counts, not a real-time measurement network.
NOAA ionospheric modelAssimilated model context with quality flags, timestamps and limited resolution.
Map geometryPublished terrain or building geometry where coverage is available.

Request geographic context

Use explicitly chosen coordinates. The example below selects a demonstration location; it does not request the server's position. The result describes nearby catalog entries and an available model cell, not a predicted or measured reception report.

curl -X POST -H 'Content-Type: application/json' \
  -d '{"latitude": 51.5, "longitude": 0}' \
  https://en-route.ringtail-anoles.ts.net/refrax-api/v1/location

Connect a local model

The development framework includes an agent adapter for an OpenAI-compatible loopback model endpoint. Run Ollama or llama.cpp locally, choose a model that fits your computer, and use the documented adapter to interpret scientific context. The model does not execute on the observatory's data server or replace its deterministic equations.

python agent.py --model llama3.2 "Summarize the global snapshot"

For implementation details and input contracts, consult the development framework. To interpret a specific result, return to the physics guide.
